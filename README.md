# Windows Tunez 🎵

A beautiful, easy-to-use music player built with HTML, CSS, and JavaScript. **No setup required!**

Works everywhere: **Windows, Mac, Linux, iOS, Android, and more!**

## How to Use

1. **Download or clone this repository**
2. **Open `index.html` in your web browser** - That's it!
3. Click the "📁 Load Songs" button to upload your own music files
4. Or use the sample songs to test it out

## Features

✅ Play, pause, next, and previous controls
✅ Upload your own music files
✅ Progress bar with seek functionality
✅ Volume control
✅ Playlist view
✅ Current time and duration display
✅ Beautiful UI with animations
✅ Responsive design (works on all devices)
✅ Saves playlist to browser storage

## Supported Formats

- MP3
- WAV
- OGG
- FLAC
- And most other audio formats

## How It Works

- **No server needed** - Everything runs in your browser
- **No installation** - Just open the HTML file
- **Auto-saves** - Your playlist is saved automatically
- **Works offline** - Once you load songs, no internet needed
- **Universal** - Works on Windows, Mac, Linux, iOS, Android, and any device with a web browser
